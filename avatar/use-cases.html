放进去，只需要一个 canvas

零依赖、不请求任何外部接口，素材与页面同源即可。同 seed 出同一张图，能按用户 ID 稳定分配。

<!-- 1. 引入引擎（零依赖，无框架） -->
<script src="mc-avatar.js"></script>

<!-- 2. 在要放头像的位置放一个 canvas -->
<canvas id="me" width="200" height="200"></canvas>

// 3. 一行画出来（不传参数就随机，传 seed 就固定）
McAvatar.draw(document.getElementById("me"), { seed: "user-1024" });
